# Соответствие классов

| Исходный класс (Контекстная диаграмма) | Уточнённый класс | Детальный класс |
| -------------------------------------- | ---------------- | --------------- |
| Стандарты                              | `...`            | `...`           |
| Сценаристы                             | `...`            | `...`           |
| Нормативные документы                  | `...`            | `...`           |
| База знаний производства               | `ФабрикаSQLiteVec` | `ФабрикаSQLiteVec` |
| Действия                               | `ШагСценария`    | `ШагСценария`   |
| Модели ИИ                              | `АгентСценарист` | `АгентСценарист` |
| Сценарии                               | `Сценарий`       | `Сценарий`      |
| VR-тренажёры                           | `...`            | `...`           |
| Пользователи                           | `...`            | `...`           |

Примечание: в пакете «Обработка эмбеддингов» сущностям контекстной диаграммы соответствуют: «Модели ИИ» — `АгентСценарист` (`ScenarAIstAgent`), «Сценарии» — `Сценарий` (`Scenario`), «Действия» — `ШагСценария` (`ScenarioStep`, включающий поле `action`), «База знаний производства» — `ФабрикаSQLiteVec` (`SQLiteVecFactory`, векторное хранилище документов). Остальные сущности (Стандарты, Нормативные документы, Сценаристы как действующее лицо, VR-тренажёры, Пользователи) не имеют соответствующих классов в исходном коде пакета и помечены `...`.
