# Соответствие классов

> **Задача**: Привести диаграмму в соответствие с логикой работы агента-Сценариста и ядра программы.
> Для каждого класса из `diagrammy/2. Контекстная диаграмма классов.md` необходимо определить соответствующий класс из `diagrammy/Пакет Обработка эмбеддингов/1. Исходная диаграмма классов.md`.
> Каждому классу исходной диаграммы должен соответствовать ровно один класс из `diagrammy/Пакет Обработка эмбеддингов/4. Детальная диаграмма классов.md`.
> Если соответствие между классом контекстной диаграммы и данным классом отсутствует, укажи `...`.
> Вспомогательные файлы: - `src/agent/*`
