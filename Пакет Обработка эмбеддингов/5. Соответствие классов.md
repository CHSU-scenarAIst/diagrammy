# Соответствие классов

> **Задача**: Привести таблицу в соответствие с диаграммами.
> Для каждого класса из `diagrammy/Пакет Обработка эмбеддингов/4. Детальная диаграмма классов.md` необходимо определить соответствующий класс из `diagrammy/Пакет Обработка эмбеддинговтеля/3. Уточнённая диаграмма классов.md`, а ему - соответсвующий из `diagrammy/2. Контекстная диаграмма классов.md`.
> Каждому классу исходной диаграммы соответствует ровно один класс из `diagrammy/Пакет Обработка эмбеддингов/4. Детальная диаграмма классов.md`.
> Если одному классу исходной диаграммы соостветвует несколько классов, перечисли их через запятую.
> Если соответствие между классом контекстной диаграммы и данным классом отсутствует, укажи "-".
> Вспомогательные файлы: `src/agent/*`
