## Таблица ... / Описание полей класса «Config»

| Название       | Тип            | Описание                          |
| -------------- | -------------- | --------------------------------- |
| base_url       | String         | Базовый URL LLM/API сервиса.      |
| api_key        | String         | Ключ доступа к API.               |
| chat_model_id  | String         | Идентификатор чат-модели.         |
| system_prompt  | String         | Системный промпт для модели.      |
| temperature    | f64            | Параметр случайности генерации.   |
| embed_model_id | String         | Идентификатор модели эмбеддингов. |
| max_tokens     | u64            | Максимум токенов ответа.          |
| chunk_size     | usize          | Размер чанка документа.           |
| chunk_overlap  | usize          | Перекрытие чанков.                |
| qdrant_url     | Option<String> | URL хранилища векторов Qdrant.    |
| top_k          | usize          | Количество результатов поиска.    |
| documents_path | String         | Путь к документам.                |
| host           | String         | Хост веб-сервиса.                 |
| port           | String         | Порт веб-сервиса.                 |
