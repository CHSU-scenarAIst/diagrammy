## Условные обозначения

| Символ          | Значение                  |
| --------------- | ------------------------- |
| `+`             | public                    |
| `-`             | private                   |
| `#`             | protected                 |
| `~`             | internal                  |
| `<<abstract>>`  | абстрактный класс         |
| `<<interface>>` | интерфейс                 |
| `<<static>>`    | статический класс         |
| `*`             | множество (0..* или 1..*) |
| `0..1`          | ноль или один             |
| `1`             | ровно один                |

 Диаграмма должна содержать для каждого класса:
 
 1) тип + имя типа
 2) поля + тип + доступность
 3) методы + тип возвращаемого значения + входные параметры с типами + доступность (если типы длинные и вложенные, то указывать основное, а громоздкое в \<...\>)
 4) связи с другими классами + тип (Ассоциация, Зависимость, наследование, Агрегация, Композиция, Реализация) + мощность
