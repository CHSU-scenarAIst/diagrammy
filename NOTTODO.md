## 2. Интерфейс пользователя

### 2.1. Исходная диаграмма классов

- Файл: `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
- Задача: Привести диаграмму в соответствие с бизнес-логикой и пользовательским интерфейсом.
Возьми названия классов/компонентов из `src/ui/...` (`.py` и `.qml`), переведи их на русский язык в нотации "НазваниеКласса".
Укажи их на диаграмме, их направления связей.
Каждую связь подпиши одним словом, обозначающим действие исходящего класса по отношению к целевому классу.
Направление стрелки должно соответствовать направлению взаимодействия: от инициатора действия к его получателю.
Составь таблицу описания назначений классов, бери описания только из их docstring в коде программы.
Не допускается приписывать классу функциональность, не подтверждённую исходным кодом:
  - При отсутствии docstring составь описание исключительно на основании фактической реализации класса.
  - Добавь сформированное описание в docstring соответствующего класса.
Таблица описания должна содержать все классы и компоненты диаграммы.

- Файл: `diagrammy/Пакет Интерфейс пользователя/2. Диаграмма последовательностей взаимодействия объектов классов пакета.md`.

Возьми готовые названия классов из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
Должны быть три диаграммы: `Нормальный ход событий`, `Прерывание процесса системой`,`Прерывание процесса пользователем`.
Все диаграммы одного стиля, они уже прописаны и не нужно их менять.
На каждой диаграмме должны присутствовать ВСЕ классы из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
Наличие всех классов на каждой диаграмме не означает обязательного участия каждого класса в каждом взаимодействии.
Классы, не участвующие в конкретном сценарии, должны присутствовать на диаграмме, но не должны иметь искусственно созданных взаимодействий.
Подпиши операции исходя из того, что один класс делает с другим классом (не обязательно одним словом).
Вспомогательные файлы:

### Условные обозначения

| Символ          | Значение                      |
| --------------- | ----------------------------- |
| `+`             | public                        |
| `-`             | private                       |
| `#`             | protected                     |
| `~`             | internal                      |
| `<<abstract>>`  | абстрактный класс             |
| `<<interface>>` | интерфейс                     |
| `<<static>>`    | статический класс             |
| `*`             | множество (`0..*` или `1..*`) |
| `0..1`          | ноль или один                 |
| `1`             | ровно один                    |
