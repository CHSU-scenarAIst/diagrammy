
| Символ          | Значение                  |
| --------------- | ------------------------- |
| `+`             | public                    |
| `-`             | private                   |
| `#`             | protected                 |
| `~`             | internal                  |
| `<<abstract>>`  | абстрактный класс         |
| `<<interface>>` | интерфейс                 |
| `<<static>>`    | статический класс         |
| `*`             | множество (0..* или 1..*) |
| `0..1`          | ноль или один             |
| `1`             | ровно один                |
