"Создание нового сценария/Изменение существующего сценария"

```mermaid
%%{init: {'theme': 'base', 'themeVariables': { 'primaryColor': '#fff', 'edgeColor': '#000', 'lineColor': '#000', 'actorTextColor': '#000'}}}%%
sequenceDiagram
    actor User as Пользователь (Сценарист)
    participant UI as ИнтерфейсПользователя
    participant Controller as КонтроллерСценария
    participant AI as МодельИИ (LlmAgent)
    participant KB as БазаЗнаний (LlmIndex)
    participant Storage as Хранилище (БазаДанных)

    User->>UI: Выбрать "Создать/Изменить сценарий"
    UI->>Controller: СоздатьЗапрос(параметры)
    Controller->>AI: СгенерироватьСценарий(параметры)
    
    Note over AI: ВИ "Генерация сценария" (include)
    AI->>KB: ПолучитьНормативныеДокументы()
    KB-->>AI: Нормативные документы
    AI->>AI: Рассчитать структуру по алгоритму
    AI-->>Controller: ОбъектСценария
    
    Controller->>Storage: СохранитьСценарий(объект)
    Storage-->>Controller: Подтверждение записи
    Controller-->>UI: Сценарий успешно сохранён
    UI-->>User: Сценарий успешно сохранён

```

"Получение сценария определённой версии"

```mermaid
%%{init: {'theme': 'base', 'themeVariables': { 'primaryColor': '#fff', 'edgeColor': '#000', 'lineColor': '#000'}}}%%
sequenceDiagram
    actor User as Пользователь (Сценарист)
    participant UI as ИнтерфейсПользователя
    participant Controller as КонтроллерСценария
    participant Storage as Хранилище (БазаДанных)
    participant Scenario as Сценарий

    User->>UI: Запросить получение сценария
    UI->>Controller: ПолучитьСписокВерсий(idСценария)
    
    Note over Controller: ВИ "Получение всех версий" (include)
    Controller->>Storage: Запрос списка версий сценария ID
    Storage-->>Controller: Список ревизий (v1, v2... vn)
    Controller-->>UI: Список версий
    UI-->>User: Показать список версий
    
    alt Выбор конкретной версии
        User->>UI: Выбрать версию №X
        UI->>Controller: ЗагрузитьВерсию(idСценария, версия)
    else Выбор последней версии (extend)
        User->>UI: Выбрать "Последняя версия"
        UI->>Controller: ЗагрузитьПоследнююВерсию(idСценария)
        Controller->>Controller: Определить версию с макс. ID
    end
    
    Controller->>Storage: Загрузить данные версии
    Storage-->>Controller: Контент сценария
    Controller->>Scenario: СоздатьОбъектСценария(данные)
    Scenario-->>Controller: ОбъектСценария
    Controller-->>UI: Отобразить сценарий
    UI-->>User: Отобразить сценарий на экране

```

"Удаление сценария"

```mermaid
%%{init: {'theme': 'base', 'themeVariables': { 'primaryColor': '#fff', 'edgeColor': '#000', 'lineColor': '#000'}}}%%
sequenceDiagram
    actor User as Пользователь (Сценарист)
    participant UI as ИнтерфейсПользователя
    participant Controller as КонтроллерСценария
    participant Storage as Хранилище (БазаДанных)

    User->>UI: Удалить сценарий
    UI->>Controller: ЗапросУдаления(idСценария)
    
    Note over Controller: ВИ "Проверка дочерних сценариев" (include)
    Controller->>Storage: Найти ссылки на сценарий в других ветках
    Storage-->>Controller: Список дочерних элементов (пусто/не пусто)
    
    alt Дочерние сценарии найдены
        Controller-->>UI: Удаление запрещено (есть зависимости)
        UI-->>User: Удаление запрещено (есть зависимости)
    else Зависимостей нет
        Controller-->>UI: Запрос подтверждения удаления
        UI-->>User: Запрос подтверждения удаления
        User->>UI: Подтвердить
        UI->>Controller: ПодтверждениеУдаления()
        Controller->>Storage: Удалить запись сценария и его версий
        Storage-->>Controller: OK
        Controller-->>UI: Сценарий успешно удалён
        UI-->>User: Сценарий успешно удалён
    end

```
