## Создание нового сценария

```mermaid
%%{init: {
  'theme': 'base',
  'themeVariables': {
    'primaryColor': '#fff',
    'primaryBorderColor': '#000',
    'lineColor': '#000',
    'tertiaryColor': '#fff',
    'edgeColor': '#000',
    'fontFamily': 'arial',
    'fontSize': '16px'
  }
}}%%
sequenceDiagram
    actor User as Сценарист
    participant System as : Система

    User->>System: Выбрать "Создать сценарий" ()
    User->>System: Заполнить форму (параметры)
    User->>System: Сохранить сценарий (объект сценария)
```

## Получение сценария определённой версии

```mermaid
%%{init: {
  'theme': 'base',

    'lineColor': '#000',
    'tertiaryColor': '#fff',
    'edgeColor': '#000',
    'fontFamily': 'arial',
    'fontSize': '16px'
  }
}}%%
sequenceDiagram
    actor User as Сценарист
    participant System as : Система

    User->>System: Запросить получение сценария (id сценария)
    User->>System: Выбрать версию  сценария (id версии)
    User->>System: Выбрать последнюю версию сценария ()
```
