# Диаграмма последовательностей взаимодействия объектов классов пакета

> **Задача**: Привести диаграмму в соответствие с бизнес-логикой и пользовательским интерфейсом.
> Возьми готовые названия классов из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
> Должны быть три диаграммы: `Нормальный ход событий`, `Прерывание процесса системой`,`Прерывание процесса пользователем`.
> Все диаграммы одного стиля, стили уже прописаны и не нужно их менять.
> Последовательность классов должна быть единой для всех трёх диаграмм.
> На каждой диаграмме должны присутствовать ВСЕ классы из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
> Наличие всех классов на каждой диаграмме не означает обязательного участия каждого класса в каждом взаимодействии.
> Классы, не участвующие в конкретном сценарии, должны присутствовать на диаграмме, но не должны иметь искусственно созданных взаимодействий.
> Подпиши операции исходя из того, что один класс делает с другим классом (не обязательно одним словом).
> Вспомогательные файлы: - `src/ui/*`.

## Нормальный ход событий

```mermaid
sequenceDiagram
    actor Сценарист
    participant Пользовательский Интерфейс
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant Запросы Пользователя
    participant ОтветАгента
    participant Панель ГорячихКлавиш
    participant Обработчик
    participant ВызовАгента

    Сценарист->>Пользовательский Интерфейс: создать UI
	Пользовательский Интерфейс->>Обработчик: создать обработчик
	Обработчик-->>Пользовательский Интерфейс: обработчик
	Пользовательский Интерфейс->>ГлавноеОкно: загрузить интерфейс
	Пользовательский Интерфейс-->>Сценарист: объект UI
    Сценарист->>ГлавноеОкно: запустить UI

    ГлавноеОкно->>СтрокаСтатуса: задать текст состояния
    ГлавноеОкно->>Запросы Пользователя: создать список задач
    ГлавноеОкно->>ОтветАгента: задать текст ответа
    ГлавноеОкно->>Панель ГорячихКлавиш: задать обработчики горячих клавиш
    ГлавноеОкно-->>Сценарист: прослушивание пользовательского ввода

    Сценарист->>Панель ГорячихКлавиш: нажать Ctrl+Space
    Панель ГорячихКлавиш->>ГлавноеОкно: отправить запросы
    ГлавноеОкно->>Запросы Пользователя: получить первый непустой запрос
    Запросы Пользователя-->>ГлавноеОкно: запрос
    ГлавноеОкно->>Обработчик: createOne(запрос)
    Обработчик->>ВызовАгента: invoke(текст запроса)
    ВызовАгента-->>Обработчик: ответ агента-Сценариста
    Обработчик->>Обработчик: сохранить ответ в файл
    Обработчик-->>ГлавноеОкно: responseReady(ответ)
    ГлавноеОкно->>ОтветАгента: задать текст ответа
    Обработчик-->>ГлавноеОкно: queryProcessed(uid)
    ГлавноеОкно->>Запросы Пользователя: удалить обработанный запрос
    ГлавноеОкно->>СтрокаСтатуса: обновить текст состояния
```

## Прерывание процесса системой

```mermaid
sequenceDiagram
    actor Сценарист
    participant Пользовательский Интерфейс
    participant Обработчик
    participant ВызовАгента
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant Запросы Пользователя
    participant ОтветАгента
    participant Панель ГорячихКлавиш

    Пользовательский Интерфейс->>Обработчик: Создать обработчик сигналов
    Пользовательский Интерфейс->>ГлавноеОкно: Загрузить интерфейс
    Сценарист->>Панель ГорячихКлавиш: Нажать Ctrl+Space
    Панель ГорячихКлавиш->>ГлавноеОкно: Отправить запросы
    ГлавноеОкно->>Запросы Пользователя: Получить непустой запрос
    ГлавноеОкно->>Обработчик: createOne(запрос)
    Обработчик->>ВызовАгента: invoke(текст запроса)
    Note over ВызовАгента: Ошибка обработки запроса агентом
    ВызовАгента--xОбработчик: Исключение
    Note over Обработчик,ГлавноеОкно: Обработка запроса прерывается<br/>сигналы responseReady и queryProcessed не отправляются
    Note over ГлавноеОкно,ОтветАгента: Ответ не отображается<br/>запрос не удаляется
```

## Прерывание процесса пользователем

```mermaid
sequenceDiagram
    actor Сценарист
    participant Пользовательский Интерфейс
    participant Обработчик
    participant ВызовАгента
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant Запросы Пользователя
    participant ОтветАгента
    participant Панель ГорячихКлавиш

    Пользовательский Интерфейс->>Обработчик: Создать обработчик сигналов
    Пользовательский Интерфейс->>ГлавноеОкно: Загрузить интерфейс
    Сценарист->>Панель ГорячихКлавиш: Нажать Ctrl+Q
    Панель ГорячихКлавиш->>ГлавноеОкно: Открыть диалог выхода
    ГлавноеОкно-->>Сценарист: Показать диалог подтверждения
    Сценарист->>ГлавноеОкно: Подтвердить выход
    ГлавноеОкно->>ГлавноеОкно: Завершить приложение
    Note over Пользовательский Интерфейс: Приложение закрыто
```
