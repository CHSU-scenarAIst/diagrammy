# Диаграмма последовательностей взаимодействия объектов классов пакета

> **Задача**: Привести диаграмму в соответствие с бизнес-логикой и пользовательским интерфейсом.
> Возьми готовые названия классов из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
> Должны быть три диаграммы: `Нормальный ход событий`, `Прерывание процесса системой`,`Прерывание процесса пользователем`.
> Все диаграммы одного стиля, они уже прописаны и не нужно их менять.
> На каждой диаграмме должны присутствовать ВСЕ классы из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
> Наличие всех классов на каждой диаграмме не означает обязательного участия каждого класса в каждом взаимодействии.
> Классы, не участвующие в конкретном сценарии, должны присутствовать на диаграмме, но не должны иметь искусственно созданных взаимодействий.
> Подпиши операции исходя из того, что один класс делает с другим классом (не обязательно одним словом).
> Вспомогательные файлы:
>     - `src/ui/*`.

## Нормальный ход событий

```mermaid
sequenceDiagram
    actor Сценарист
    participant ПользовательскийИнтерфейс
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant ЗапросыПользователя
    participant ОтветАгента
    participant ПанельГорячихКлавиш
    participant ОбработчикСигналов
    participant ВызовАгента

 Сценарист->>ПользовательскийИнтерфейс: создать UI
    ПользовательскийИнтерфейс->>ОбработчикСигналов: создать обработчик
 ОбработчикСигналов-->>ПользовательскийИнтерфейс: обработчик
 ПользовательскийИнтерфейс-->>Сценарист: объект UI
    Сценарист->>ГлавноеОкно: запустить UI

    ГлавноеОкно->>СтрокаСтатуса: собрать
    СтрокаСтатуса-->>ГлавноеОкно: компонент
    ГлавноеОкно->>ЗапросыПользователя: собрать
    ЗапросыПользователя-->>ГлавноеОкно: компонент
    ГлавноеОкно->>ОтветАгента: собрать
    ОтветАгента-->>ГлавноеОкно: компонент
    ГлавноеОкно->>ПанельГорячихКлавиш: собрать, задать обработчики горячих клавиш
    ПанельГорячихКлавиш-->>ГлавноеОкно: компонент
    ГлавноеОкно-->>Сценарист: прослушивание пользовательского ввода

    Сценарист->>ПанельГорячихКлавиш: Нажать Ctrl+Space
    ПанельГорячихКлавиш->>ГлавноеОкно: Отправить запросы
    ГлавноеОкно->>ЗапросыПользователя: Получить непустой запрос
    ГлавноеОкно->>ОбработчикСигналов: createOne(запрос)
    ОбработчикСигналов->>ВызовАгента: invoke(текст запроса)
    ВызовАгента-->>ОбработчикСигналов: Ответ агента-Сценариста
    ОбработчикСигналов->>ОбработчикСигналов: Сохранить ответ в файл
    ГлавноеОкно->>ОтветАгента: Отобразить ответ
    ГлавноеОкно->>ЗапросыПользователя: Удалить обработанный запрос
    ГлавноеОкно->>СтрокаСтатуса: Обновить статус
```

## Прерывание процесса системой

```mermaid
sequenceDiagram
    actor Сценарист
    participant ПользовательскийИнтерфейс
    participant ОбработчикСигналов
    participant ВызовАгента
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant ЗапросыПользователя
    participant ОтветАгента
    participant ПанельГорячихКлавиш

    ПользовательскийИнтерфейс->>ОбработчикСигналов: Создать обработчик сигналов
    ПользовательскийИнтерфейс->>ГлавноеОкно: Загрузить интерфейс
    Сценарист->>ПанельГорячихКлавиш: Нажать Ctrl+Space
    ПанельГорячихКлавиш->>ГлавноеОкно: Отправить запросы
    ГлавноеОкно->>ЗапросыПользователя: Получить непустой запрос
    ГлавноеОкно->>ОбработчикСигналов: createOne(запрос)
    ОбработчикСигналов->>ВызовАгента: invoke(текст запроса)
    Note over ВызовАгента: Ошибка обработки запроса агентом
    ВызовАгента--xОбработчикСигналов: Исключение
    Note over ОбработчикСигналов,ПользовательскийИнтерфейс: Исключение логируется
    Note over ГлавноеОкно,ОтветАгента: Ответ не отображается<br/>запрос не удаляется
```

## Прерывание процесса пользователем

```mermaid
sequenceDiagram
    actor Сценарист
    participant ПользовательскийИнтерфейс
    participant ОбработчикСигналов
    participant ВызовАгента
    participant ГлавноеОкно
    participant СтрокаСтатуса
    participant ЗапросыПользователя
    participant ОтветАгента
    participant ПанельГорячихКлавиш

    ПользовательскийИнтерфейс->>ОбработчикСигналов: Создать обработчик сигналов
    ПользовательскийИнтерфейс->>ГлавноеОкно: Загрузить интерфейс
    Сценарист->>ПанельГорячихКлавиш: Нажать Ctrl+Q
    ПанельГорячихКлавиш->>ГлавноеОкно: Открыть диалог выхода
    ГлавноеОкно-->>Сценарист: Показать диалог подтверждения
    Сценарист->>ГлавноеОкно: Подтвердить выход
    ГлавноеОкно->>ГлавноеОкно: Завершить приложение
    Note over ПользовательскийИнтерфейс: Приложение закрыто
```
