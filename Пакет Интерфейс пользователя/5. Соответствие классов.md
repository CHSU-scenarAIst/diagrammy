# Соответствие классов

> **Задача**: Привести диаграмму в соответствие с бизнес-логикой и пользовательским интерфейсом.
> Для каждого класса из `diagrammy/2. Контекстная диаграмма классов.md` необходимо определить соответствующий класс из `diagrammy/Пакет Интерфейс пользователя/1. Исходная диаграмма классов.md`.
> Каждому классу исходной диаграммы должен соответствовать ровно один класс из `diagrammy/Пакет Интерфейс пользователя/4. Детальная диаграмма классов.md`.

> Вспомогательные файлы:
>     - `src/ui/*`.
